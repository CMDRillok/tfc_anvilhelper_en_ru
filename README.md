# TFC Forge Calc

Помощник для кузнечного мини-игр (anvil) в моде **TerraFirmaCraft** для Minecraft.

## Возможности

- **Path** — по конечной координате подбирает последовательность ударов, которая приведёт заготовку в нужную точку.
- **End** — суммирует выполненные удары и показывает итоговую координату.

Удары: `Усадить (+16)`, `Обжать (+13)`, `Изогнуть (+7)`, `Штамповать (+2)`,
`Слабо ударить (−3)`, `Ударить (−6)`, `Сильно ударить (−9)`, `Протянуть (−15)`.

## Запуск

Нужен Python 3 с Tkinter (входит в стандартную поставку на Windows/macOS,
на Linux может потребоваться пакет `python3-tk`).

```bash
python calc.py
```

В поле координаты введите целое число и нажмите «Высчитать» (или Enter).

## Что улучшено

- Убран дублирующийся код: 16 отдельных обработчиков заменены одним методом.
- Исправлена ошибка: при неверном вводе программа больше не продолжает
  вычисления с неинициализированными переменными.
- Заменён жадный подбор ударов на поиск в ширину — теперь находится
  **минимальное** число ударов и исключено бесконечное зацикливание
  (например, для цели `1`).
- `Reset` очищает и надпись, вкладка «End» показывает набранные удары.
- Убраны неиспользуемые импорты, глобальные переменные и мёртвый код.
- Добавлена проверка диапазона ввода и вывод количества ударов.
